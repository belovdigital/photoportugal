# Database — где смотреть схему

Табличная копия схемы, жившая в этом файле, к августу 2026 отстала от прода на
40+ таблиц — по ней писались запросы к несуществующим колонкам. Удалена, чтобы
не врала. Смотреть:

- **Схема:** [`db/schema.sql`](../db/schema.sql) — генерируется с прода PT,
  дата генерации в шапке файла. Обновить: `scripts/refresh-schema.sh`
  (запускать после каждой миграции). PT каноничен — все три рынка живут на
  одних миграциях.
- **Смысл полей, статусы, инварианты:** [`docs/DOMAIN.md`](DOMAIN.md) — в том
  числе §7 «поля, которые врут» (NUMERIC приходит строкой, `created_at` — не
  дата апрува, и т.д.).
- **Миграции:** `db/migrations/` (нумерованные) + исторические `db/*.sql`.
- Истина последней инстанции — живая база: перед деплоем нового SQL прогнать
  его read-only на проде (правило в CLAUDE.md и
  `memory/feedback_verify_sql_before_deploy`).
