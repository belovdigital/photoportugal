# PhotoTravel — агентный канал (MCP)

Один эндпоинт, через который ChatGPT и любой другой MCP-клиент бронируют
съёмку напрямую в нашем движке, вместо того чтобы «ходить по сайту».
Название бренда — **PhotoTravel**, оно не привязано к стране, поэтому
переживёт добавление рынков.

Собрано 2026-08-02.

## Адрес

```
POST https://photoportugal.com/api/mcp
```

Роут лежит в общем репозитории, поэтому физически он есть и на
`photospain.co`. Канонический — португальский; испанский не публикуем,
чтобы у клиента был один адрес.

## Что канал умеет и почему так мало

Только **слепая бронь**: путешественник называет место, дату и повод,
платит фиксированную all-in цену, фотографа мы подбираем в течение 24 часов.

Это ограничение — осознанное. Доступность конкретного фотографа приходит из
синка календарей, где частичная выгрузка читается как «свободно», а не как
ошибка (см. `calendar_sync_google_freebusy`). Агент, уверенно продающий
занятый слот, хуже, чем отсутствие агента. У слепой брони такого режима
отказа нет, а цена, оплата и обещание подбора в ней уже есть.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `list_destinations` | Все направления, где мы сейчас снимаем. Отдаёт точные слаги для остальных вызовов. Есть фильтр по области. |
| `get_photoshoot_quote` | Точная all-in цена. Внутренние суммы наружу не идут — см. ниже. |
| `create_photoshoot_booking` | Создаёт реальную бронь и возвращает ссылку на Stripe Checkout. |

Три, а не девять: чем больше инструментов, тем хуже модель выбирает.

## Деньги — что нельзя отдавать модели

Апстрим `/api/blind-booking/price` возвращает ещё `base_eur`,
`service_fee_eur` и `regional_base_eur` — это ставка фотографа и наша
комиссия. В `route.ts` ответ **сужается вручную**: наружу уходит только
`total_eur` (плюс зачёркнутая цена и экономия).

Если будешь добавлять поля — не копируй ответ апстрима целиком.

## Испания выключена

`MARKETS.spain.enabled = false` в `src/lib/phototravel/catalogue.ts`.
Испанские направления отфильтрованы во всех трёх инструментах: `barcelona`
отвечает «мы там пока не снимаем».

Причина: нет одобренных фотографов. Взять бронь, которую мы не сможем
закрыть, хуже, чем не появиться в канале.

**Включение — одна строка**: `enabled: true`. Всё остальное (каталог из 23
испанских городов, маршрутизация на `photospain.co`) уже написано.

## Ключ канала

`AGENT_CHANNEL_KEY` в `.env` на проде Португалии.

Зачем: все брони из ChatGPT идут через наш сервер и делят один IP, поэтому
упирались бы в per-IP антиспам (5/мин), рассчитанный на браузеры. Ключ
снимает именно IP-лимит; лимит по email остаётся, плюс добавлен общий
потолок на канал (60/мин).

Если переменной нет — заголовок не отправляется, поведение ровно прежнее.
Значение без `#`, иначе `@next/env` обрежет (см. `env_hash_truncates_values`).

## Атрибуция

Брони из канала помечаются `utm_source = 'phototravel'`
(`utm_medium` остаётся `blind_booking`, чтобы существующие фильтры по
слепой воронке не сломались).

Посмотреть:

```sql
SELECT count(*), sum(total_price + service_fee) AS klient_zaplatil
FROM bookings WHERE utm_source = 'phototravel';
```

## Протокол

JSON-RPC 2.0 поверх одного POST, без состояния. Методы: `initialize`,
`ping`, `tools/list`, `tools/call`, плюс уведомления (без `id` → 202).

SDK от MCP не используется намеренно: его HTTP-транспорты хотят сырые
`req`/`res` от Node, которых роут-хендлер Next не отдаёт. Нужная поверхность
— четыре метода.

`protocolVersion` эхоится обратно клиенту: version-specific поведения у
сервера нет, а эхо оставляет совместимость с клиентами новее этого файла.

Ошибки уровня инструмента (неизвестный город, дата в прошлом) возвращаются
как `isError: true` внутри успешного результата, а не как ошибка протокола —
иначе модель не переспросит с исправленными аргументами.

## Проверка

```bash
U=https://photoportugal.com/api/mcp
curl -s -X POST $U -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | python3 -m json.tool
```

Прогон 2026-08-02: `initialize`, `tools/list`, каталог (22 направления,
только Португалия), цена (€279 all-in, внутренние суммы не утекли), отказы
(испанский город, выдуманный город, неверный повод, неверная длительность,
дата в прошлом, кривая почта) и **реальная бронь** — Sintra 15.10.2026,
`utm_source=phototravel`, живая ссылка Stripe. Тестовые бронь, пользователь
и сессия Stripe удалены.

## Что дальше, если понадобится

- **Каталог фотографов в чате** — только вместе с честной доступностью,
  которая падает в «нет данных», а не в «свободно».
- **Статус брони** — нужен способ опознать пользователя; сейчас его нет.
- **Свой поддомен** вместо `photoportugal.com/api/mcp`, когда канал
  перестанет быть экспериментом.
- **Оплата внутри чата** — у OpenAI пока в бете для избранных партнёров,
  так что ссылка на Checkout остаётся правильным решением.
